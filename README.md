## Быстрая установка

Запустите команду в терминале в зависимости от вашей системы:

### Linux / macOS
curl -fsSL https://xbox-dns.ru/softwares/agy/install.sh | bash

### Windows (PowerShell)
irm https://xbox-dns.ru/softwares/agy/install.ps1 | iex

---

## Инструкция

1. Откройте терминал (PowerShell или Terminal).
2. Запустите соответствующую команду.
3. В появившемся интерактивном меню выберите, что именно требуется пропатчить:
   * Antigravity 2.0
   * Antigravity IDE
   * Antigravity CLI
4. Дождитесь завершения настройки.
5. Готово! Перезапустите приложение или сессию терминала.
